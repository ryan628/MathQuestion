# 中小学数学口算题出题系统 (苏教版 1-9年级)

基于 Java 17 + JavaFX 开发的中小学数学口算与代数速算自动出题系统。涵盖苏教版（含苏科版初中）小学 1-6 年级及初中 7-9 年级全 18 个学期，支持一键生成规范排版的 Word 试卷（`口算题.docx`），并内置了开源专业数学字体与高清桌面图标。

---

## 🌟 核心特性

1. **全面覆盖义务教育数学 1-9 年级（全 18 学期，120+ 题型）**：
   - **小学低段 (1-2年级)**：20以内进退位加减、100以内整十加减、表内乘除、乘加乘减两步等 51 种经典基础题型；
   - **小学中段 (3-4年级)**：多位数乘除一位数、整十整百乘除、同分母分数加减、小数加减、混合运算律简算等；
   - **小学高段 (5-6年级)**：小数乘除法、异分母分数四则运算、简易方程、比与比例、百分数互化等；
   - **初中阶段 (7-9年级)**：有理数混合四则与乘方、整式加减、同底数幂乘除、平方差与完全平方公式、平方根/立方根、二次根式化简运算、一元二次方程口算、特殊角三角函数等。

2. **专业排版试卷导出（原生 DOCX）**：
   - 遵循 ECMA-376 (OpenXML) 国际标准，单文件生成标准的 `口算题.docx`；
   - 支持自定义题目数（默认 100 题）与出题页数（1~10页自动插入标准硬分页符，严格每页 100 题 4 列排版）；
   - 包含试卷大标题、副标题、学生信息栏（班级、学号、姓名、成绩）及四列无边框表格，WPS 与 Microsoft Word 完美打开即印。

3. **内置开源专业数学符号字体**：
   - 内置基于 SIL OFL 开源协议的 `STIX Two Math` 字体，全面支持代数变量（$x, y, a$）、根号（$\sqrt{}$）、平方立方上标（$a^2, b^3$）、特殊角（$30^\circ$）等复杂数学符号，排版优雅无乱码。

4. **现代化 JavaFX 界面与专属高清图标**：
   - 扁平现代卡片式双区分区选择（小学 6 个年级 + 初中 3 个年级），支持实时弹窗预览试卷题目与参考答案；
   - 提供 256×256 高清透明 Squircle 应用图标与 Windows `.ico` 桌面图标。

## 🛠 技术栈与环境要求

- **JDK**: Java 17 或更高版本
- **GUI 框架**: JavaFX 17 (OpenJFX)
- **构建工具**: Apache Maven 3.8+
- **运行环境**: Windows / macOS / Linux

---

## 🚀 编译与运行指南

### 1. 源码编译与打包
```bash
# 运行单元测试
mvn test

# 打包全依赖独立运行包 (FAT JAR)
mvn clean package -DskipTests
```
打包成功后，可在 `target/` 目录下获得 `math-question-1.0.0.jar`。

### 2. 运行程序
```bash
java -jar target/math-question-1.0.0.jar
```
也可以在 Windows 桌面双击快捷方式或运行 `run.bat` 极速启动。
